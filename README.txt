INTERFACE MODERNA - A ESPUMA ERA LEI

Estrutura:
  html/     -> páginas
  css/      -> style.css
  imagens/  -> imagens diversas
  js/       -> common.js

As imagens continuam sendo lidas de ../Imagens/ com os mesmos nomes usados no projeto original.

O projeto usa Bootstrap 5 via CDN e localStorage apenas para manter o carrinho entre as páginas.
Nenhum PHP/SQLite é necessário para esta versão focada em interface/interatividade.

  html/Cafeteiras.html
  html/Capsulas.html
  html/Pedidos.html
  html/DadosPagamento.html
